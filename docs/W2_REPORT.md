## 2. 핵심 설계

### 2.1 OS-rendered timer (PLAN §6)
`TimerLiveActivity` 가 `Text(timerInterval: startedAt..., countsDown: false)` 사용. 앱이 매초 깨워 update 호출할 필요 없음. `pausedAt` 이 nil 이면 OS 가 자동 카운트, non-nil 이면 frozen `Duration` 표시.

### 2.2 ActivityContent 업데이트 시점
- `AppState.startSession` → `liveActivity.start(...)`
- `AppState.pauseSession` → `liveActivity.pause(at: now, accumulatedSeconds:)`
- `AppState.resumeSession` → `liveActivity.resume(newStartedAt:, carriedAccumulatedSeconds:)` (resume 시 startedAt 을 과거로 보정해 OS 가 계속 누적해 보이도록)
- `AppState.persist` → `liveActivity.end()` (dismissal `.immediate`)

### 2.3 위젯 데이터 전송
- 동일 컨테이너 메모리 공유 X. `UserDefaults(suiteName: AppGroup.identifier)` 로 단순 키 3개 (`dday.*`) + 1개 (`today.studySeconds`)
- `WidgetSyncService.syncAll(context:)` 가 디데이 + 오늘 순공 동기화 + `WidgetCenter.shared.reloadAllTimelines()` 호출
- 호출 지점: `AppState.persist` (세션 종료 후)

### 2.4 권한·entitlement
- `NSSupportsLiveActivities = true` (Info.plist)
- `App Group = group.co.autopus.study` (양쪽 entitlements 파일)
- `ActivityAuthorizationInfo().areActivitiesEnabled` 체크 후에만 `Activity.request`. 실패 시 silent fallback

## 3. 발견·수정한 이슈

| 이슈 | 진단 | 처리 |
|------|------|------|
| **SwiftData sandbox `default.store` write denied** | `ModelConfiguration(isStoredInMemoryOnly: false)` 기본 URL 이 `Library/Application Support`. 새 시뮬 컨테이너에서 sandbox 가 디렉토리 생성 차단 | `URL.documentsDirectory.appendingPathComponent("Study.sqlite")` 로 명시. Documents 는 항상 쓰기 허용. **클린 install 정상 동작 확인** |
| TimerView pause/resume 이 AppState 미경유 | `try? appState.timer.pause(...)` 직접 호출 → LiveActivity 갱신 안 됨 | `appState.pauseSession()` / `resumeSession()` wrap 메서드 추가 |

### 시뮬레이터로 자동 검증 불가
- **LiveActivity 잠금화면**: simctl 에 lock 자동화 명령이 안정적으로 없음. macOS Accessibility 권한 없이 AppleScript lock 도 차단
- **위젯 갤러리/홈스크린**: simctl 로 홈스크린에 위젯 추가 자동화 없음

→ **사용자 수동 확인 요청**: 시뮬레이터에서
1. 타이머 시작 → Cmd+L 로 잠금 → LiveActivity 카드 보이는지
2. 홈스크린 길게 누름 → "+" → "공부어플" 위젯 검색 → D-Day / 오늘 순공 위젯 표시되는지
3. 위젯 데이터: 시드 마스코트·디데이가 보이는지 (App Group entitlement 가 시뮬에서 충분히 동작하는지)

## 5. W2 잔존·메모

- entitlement linter 가 plist 내용을 자주 비움 (별도 도구 개입 추정). 빌드는 통과하지만 실기기에서는 App Group 등록 + provisioning profile 필요. 출시 시 Apple Developer Portal 에서 App Group 등록 필수
- 위젯 timeline refresh 주기: D-Day = 익일 자정, 오늘 순공 = 15분. 활성 세션 중에도 위젯이 라이브로 안 늘어남 (OS budget 정책). LiveActivity 가 그 갭을 채움
- Dynamic Island 미니멀 모드: 색 원만 표시. compact/expanded 는 시간 + 과목명 + 색 표시
