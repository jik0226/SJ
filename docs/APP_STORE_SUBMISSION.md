## 0. 제출 전 반드시 (콘솔/계정 — 코드 아님)

1. **Firebase 콘솔 → Authentication → Sign-in method → Apple 사용 설정**
   (방금 추가한 Apple 로그인이 이거 없으면 런타임에서 실패함. 네이티브 iOS는 이것만 켜면 됨.)
2. **Firebase 콘솔 → Firestore Database → 규칙**: 저장소 `docs/SIGNING_AND_BACKEND.md`의 규칙 블록을 붙여넣고 **게시**. 게시 전 Rules Playground에서 4케이스 확인:
   - 비멤버 `groups` 목록 조회 → **거부**
   - `memberUids` array-contains 내 uid 쿼리 → **허용**
   - DM 문서(`code`가 `DM:`로 시작)에 self-join → **거부**
   - `groupCodes/{코드}` get → 그룹 self-join → **성공**
3. **Xcode에서 새 빌드 업로드**: Product → Archive → Distribute → App Store Connect → Upload.
   (버전은 1.0, 빌드 2로 이미 올려둠. Apple 로그인 capability는 Automatic signing이 자동 등록.)

## 4. 연령 등급 (Age Rating) 설문

- 사용자 생성 콘텐츠(채팅) **있음** → 정직히 "예".
- 콘텐츠 신고/차단/필터 **있음** → 해당 항목 "예"(욕설 필터·신고·차단·만14세 메시지 제한 모두 구현됨).
- 무제한 웹 접근 **없음**, 도박/성인물 **없음**.
- 위 답변으로 등급이 자동 산정됩니다(대략 12+ 예상). 실제 표시 등급은 설문 결과를 따르세요.
