# SJ(Study J) 개인정보처리방침

최종 업데이트: 2026-05-28

SJ(이하 "앱")는 이용자의 개인정보를 중요하게 생각하며, 아래와 같이 수집·이용·보관합니다. 본 방침은 TestFlight 베타 및 정식 배포에 공통 적용됩니다.

## 1. 수집하는 항목

### 1-1. 서버(Google Firebase)에 저장되는 정보
친구·채팅·다기기 동기화 기능을 사용할 때 다음이 Google Firebase(Authentication / Cloud Firestore)에 저장됩니다.

- **계정 식별자**: 익명 인증 UID(이메일·전화번호 없이 자동 생성), 친구 코드(6자리)
- **프로필**: 표시 이름(닉네임)
- **채팅**: 그룹·1:1 메시지 내용, 보낸 사람 친구 코드, 전송 시각, 공유 첨부(오늘 공부·운동·플래너·바다·연속 학습 요약)
- **학습/운동 기록**(본인 전용 백업): 과목명·색·아이콘·목표, 학습 세션 시작/종료/시간, 운동 거리·시간·칼로리·페이스, 플래너 10분 블록, 디데이, 바다(공부/운동 누적 분·시드)

### 1-2. 기기에만 저장되고 서버로 전송되지 않는 정보
- **생년월일**: 만 14세 미만 보호 정책 적용 여부 판단에만 사용하며, 기기 안에서만 처리되고 외부로 전송되지 않습니다.
- **위치 정보**: 러닝 거리·경로 측정에 사용하며, 기기와 Apple 건강 앱에만 저장되고 서버로 전송되지 않습니다.
- **건강·운동 데이터(HealthKit)**: 사용자가 허용한 경우 Apple 건강 앱과 주고받으며, Apple의 HealthKit 정책에 따라 처리되고 당사 서버로 전송되지 않습니다.

## 2. 수집·이용 목적
- 친구 추가 및 친구 코드 검증
- 1:1·그룹 채팅 송수신
- 학습/운동 성취 공유
- 같은 계정의 여러 기기 간 데이터 동기화 및 백업
- 만 14세 미만 이용자 보호(메시지 길이 제한·외부 링크 차단)

## 3. 제3자 처리 위탁
- **Google Firebase(Google LLC)**: 인증 및 데이터 저장을 위탁합니다. 데이터는 Firebase 인프라에 저장되며, Google의 개인정보처리방침(https://firebase.google.com/support/privacy)이 함께 적용됩니다.
- 그 외 광고·분석 목적의 제3자 데이터 제공은 없습니다. (Analytics·광고 SDK 미사용)

## 4. 보관 및 파기
- 서버 데이터는 익명 계정이 유지되는 동안 보관됩니다.
- 앱 삭제 시 기기 내 데이터는 삭제되며, 서버 데이터 삭제를 원하시면 아래 문의처로 계정 식별자(앱 → 더보기 → 내 프로필 → 고객지원용 ID)를 알려주시면 처리합니다.

## 5. 이용자의 권리
- 친구에게 공개할 항목(오늘 공부시간·이번주 누적·연속 학습·바다·플래너)은 앱 내 "공유 설정"에서 항목별로 켜고 끌 수 있으며, 기본값은 모두 비공개입니다.
- 친구 차단·삭제, 그룹·대화 나가기를 앱 내에서 직접 할 수 있습니다.

## 6. 만 14세 미만 아동
만 14세 미만 이용자에게는 메시지 길이 제한 및 외부 링크 차단이 자동 적용됩니다. 생년월일은 이 판단에만 쓰이며 외부로 전송되지 않습니다.
